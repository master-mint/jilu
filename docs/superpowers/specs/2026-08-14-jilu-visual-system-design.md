# 记律视觉系统重构设计

## 目标

将记律从浅色青绿应用重构为带有编辑化质感的学习控制台。日间模式采用深森林绿背景与暖白内容面板，参考图的高密度模块拼贴与克制留白；夜间模式使用柔和黑白灰阶，避免彩色状态提示，以保证长时间阅读舒适度。

本次改动覆盖仪表盘、资料库、统计、设置、弹窗及移动端导航，但不修改 IndexedDB 数据结构、FSRS 排程逻辑、导入导出格式或既有视图路由。

## 视觉令牌

### 日间

- 页面底色：深森林绿 `#16372C`，搭配低对比纹理或颗粒感。
- 主要表面：暖白 `#F3F0E7`，辅助表面使用更深一档的暖灰。
- 强调：苔藓绿 `#4D735D` 与接近黑色的文字；仅在主要操作、进度和可交互状态中使用。
- 边界与阴影：低对比细分割线和短阴影，面板圆角控制在 8px 以内。

### 夜间

- 页面底色：炭黑 `#151515`。
- 表面层次：石墨 `#232323` 和雾白文字 `#E9E8E3`。
- 所有成功、警告、危险等状态以明度、描边、图标和文案区分，不保留绿、红、橙、蓝色系。
- 交互焦点使用雾白描边或填充反差，保持 WCAG 可读性。

## 布局与组件

### 全局壳层

- 桌面端：固定窄左侧栏容纳品牌、四个视图和主题切换；右侧为滚动主工作区。
- 移动端：保留底部导航，将新增操作置于中央并遵循相同的灰阶状态。
- 顶部保留当前视图的上下文操作和添加卡片命令，避免重复导航。

### 仪表盘

- 首屏由今日复习主模块、完成进度环和记忆曲线组成，主要复习命令始终可见。
- 关键指标使用统一高度的四格微型面板，清晰展示待复习、新卡、连续天数和掌握度。
- 待复习队列、本周节奏和学习洞察使用对齐网格，不嵌套装饰性卡片。
- 现有周图表保持其数据来源和计算方式，仅更换图表容器、刻度、柱形与标签样式。

### 资料库

- 搜索和筛选放在单一工具栏内；卡片使用暖白纸张风格、细分割和紧凑元数据。
- 标题、到期状态、掌握度和编辑操作形成稳定扫描顺序。

### 统计

- 累计复习、记住率和掌握度编入单个概览带。
- 热力图、评分分布和复习趋势统一为可视化面板；空数据时显示稳定占位，避免布局跳动。
- 图表不引入外部图表库，继续用现有 DOM/CSS 输出，以保留离线可用性。

### 设置、弹窗与复习

- 设置表单采用同一表面、分割线和控件高度；主题开关与按钮遵循新的单色状态。
- 新增/编辑卡片弹窗采用暖白工作表布局，媒体上传区为明确的可点击工具面。
- 复习弹窗强调单张卡片与评级操作；评级通过位置、明度和图标区分，避免多色按钮。

## 实现边界

- 优先在 `styles.css` 中建立日间、夜间和组件令牌，减少零散硬编码色值。
- 仅在 `index.html` 中调整布局包裹、区域语义和必要的图表面板容器；现有 ID 与 `data-view` 属性保持不变，避免破坏 `js/app.js` 事件绑定。
- 仅在 `js/app.js` 中调整图表的标记结构或增加展示用数据摘要；不修改存储、排程和复习结果计算。
- 不新增运行时依赖、构建步骤或后端服务。

## 交互与错误处理

- 主题仍写入现有 `settings.theme` 并在刷新后恢复；切换时同步更新浏览器主题色。
- 空卡片、空统计、无待复习内容仍使用当前数据状态，采用新的空状态布局与文案层级。
- 主题或数据读取失败时继续复用现有 toast 和回退行为，不阻塞页面访问。

## 验证

- 桌面和移动视口：导航、主面板和图表不溢出、不重叠，文本保持可读。
- 日间和夜间：检查所有页面、弹窗、按钮、输入框、图表与焦点态均使用正确令牌；夜间页面无彩色强调残留。
- 工作流：添加、编辑、删除卡片；开始复习、显示答案、评分；视图切换；搜索筛选；导入导出；设置保存及主题持久化。
- 数据状态：空数据库和具有卡片、复习记录的数据库都能正确展示指标、热力图、评分分布与周节奏。
